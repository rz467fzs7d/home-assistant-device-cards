# Power strip artwork

Approved Chinese five-hole socket variants:

| File | Layout | USB |
| --- | --- | --- |
| `powerstrip-cn-six.svg` | Six sockets, staggered rows of three | Four ports on the left |
| `powerstrip-cn-six-no-usb.svg` | Six sockets, staggered rows of three | None |
| `powerstrip-cn-four-inline.svg` | Four sockets in one row | None |
| `powerstrip-cn-five-inline.svg` | Five sockets in one row | None |
| `powerstrip-cn-four-inline-cord.svg` | Four sockets in one row, right-side power cord | None |
| `powerstrip-cn-five-inline-cord.svg` | Five sockets in one row, right-side power cord | None |
| `powerstrip-cn-four-inline-cord-left.svg` | Four sockets in one row, left-side power cord | None |
| `powerstrip-cn-five-inline-cord-left.svg` | Five sockets in one row, left-side power cord | None |

All variants use `currentColor`, transparent cutouts, and the same socket
artwork. The four- and five-socket inline versions include additional padding
at both ends. There is no master switch in the artwork.

Select artwork through the card editor's Appearance menu or `icon_variant`.
The original remains the default. USB is decorative and never adds a control.
See `../../NOTICE.md` for upstream attribution and licensing.
