# Power strip artwork

Approved Chinese five-hole socket variants:

| File | Layout | USB |
| --- | --- | --- |
| `powerstrip-cn-six.svg` | Six sockets, staggered rows of three | Four ports on the left |
| `powerstrip-cn-six-no-usb.svg` | Six sockets, staggered rows of three | None |
| `powerstrip-cn-four-inline.svg` | Four sockets in one row | None |
| `powerstrip-cn-five-inline.svg` | Five sockets in one row | None |

All variants use `currentColor`, transparent cutouts, and the same socket
artwork. The four- and five-socket inline versions include additional padding
at both ends. There is no master switch in the artwork.

These are standalone SVG assets; adding them here does not change the card's
default icon or introduce a configuration option. See `../../NOTICE.md` for
upstream attribution and licensing.
