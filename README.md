# Home Assistant Device Cards

Dashboard cards for devices already connected to Home Assistant.

## Supported devices and services

| Device or service | Card type |
| --- | --- |
| [Power strips and outlets](docs/guide.md#power-strip) | `custom:power-strip-card` |
| [HomePod and HomePod mini stereo pairs](docs/guide.md#stereo-and-home-theater) | `custom:homepod-stereo-card` |
| [Apple TV with HomePods](docs/guide.md#stereo-and-home-theater) | `custom:apple-theater-card` |
| [Stereo speakers, including Sonos](docs/guide.md#stereo-and-home-theater) | `custom:general-speaker-stereo-card` |
| [LG ThinQ washers](docs/guide.md#washer) | `custom:washer-card` |
| [Midea AC LAN dishwashers](docs/guide.md#dishwasher) | `custom:dishwasher-card` |
| [Xiaomi Home air fryers](docs/guide.md#air-fryer-and-pressure-cooker) | `custom:air-fryer-card` |
| [Xiaomi Home pressure cookers](docs/guide.md#air-fryer-and-pressure-cooker) | `custom:pressure-cooker-card` |
| [Plant monitors](docs/guide.md#plant-monitor) | `custom:plant-monitor-card` |
| [Powered toilet seats](docs/guide.md#toilet-seat) | `custom:toilet-seat-card` |
| [PETKIT litter boxes](docs/guide.md#petkit-litter-box) | `custom:petkit-litter-card` |
| [AdGuard Home](docs/guide.md#adguard-home) | `custom:adguard-card` |

## Install with HACS

[![Open repository in HACS](https://my.home-assistant.io/badges/hacs_repository.svg)](https://my.home-assistant.io/redirect/hacs_repository/?owner=rz467fzs7d&repository=home-assistant-device-cards&category=plugin)

Add this repository to HACS as a **Dashboard** custom repository, install it,
then refresh Home Assistant and add a card. See the [guide](docs/guide.md) for
configuration examples, screenshots, and [installation details](docs/guide.md#install-with-hacs).
